# 🎯 How to Get X_BEARER_TOKEN - Step by Step

## **Why We Need It (According to X API Docs)** 📚

From [X API Getting Access documentation](https://docs.x.com/x-api/getting-started/getting-access-to-the-x-api):

> **"App only Access Token: You will use this token when making requests to endpoints that responds with information publicly available on X."**

**Our use case:**
- We search **public tweets** from insiders
- We don't need user login
- **Perfect for App-only Access Token (Bearer Token)!**

---

## **✅ EASIEST METHOD: X Developer Portal** ⭐

### **Step 1: Go to X Developer Portal**
1. Visit: https://developer.twitter.com/en/portal/dashboard
2. **Login** with your X/Twitter account

### **Step 2: Select Your Project**
1. You'll see your **Projects** list
2. Click on the project that contains your app

### **Step 3: Open Your App**
1. In the project, find your **App**
2. Click on it to open

### **Step 4: Go to Keys and Tokens**
1. Click the **"Keys and tokens"** tab
2. Scroll down to find **"Bearer Token"** section

### **Step 5: Generate Bearer Token**
1. Click **"Generate"** or **"Regenerate"** button
2. **⚠️ IMPORTANT:** The token only shows **once**!
3. **Copy it immediately** to a secure place

### **Step 6: Add to `.env.local`**
```env
X_BEARER_TOKEN=AAAAAAAAAAAAAAAAAAAAA...  # Paste your token here
```

**That's it!** ✅

---

## **Why This Method?** 🤔

**According to X API documentation:**
- ✅ **Easiest** - No coding needed
- ✅ **Guaranteed to work** - Direct from portal
- ✅ **Secure** - Generated by X platform
- ✅ **No credential issues** - Portal handles everything

**Programmatic generation (using API Key/Secret) sometimes fails because:**
- ❌ API Key/Secret might not have permission
- ❌ Endpoint might require different authentication
- ❌ Credentials might be for OAuth only, not bearer token generation

**Solution: Use Portal method!** ⭐
